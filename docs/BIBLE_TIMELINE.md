# Cronologia editorial da narrativa bíblica

## Como usar este documento

Esta é uma linha do tempo **narrativa**, não uma tabela de datas absolutas. Datas para patriarcas, êxodo, composição de livros e muitos acontecimentos antigos são debatidas. Ao usar datação, o roteiro deve informar a fonte/posição e preferir intervalos ou formulações cuidadosas. A sequência literária e a relação entre histórias podem ser apresentadas com mais segurança que uma precisão cronológica indevida.

## Protocolo para afirmações cronológicas

Antes de escrever “em [ano]” ou “por [n] anos”:

1. confirme se o número está explicitamente no texto bíblico e cite a passagem;
2. se for reconstrução histórica, registre fonte e grau de consenso no brief;
3. se houver debate relevante, use “segundo esta leitura”, “muitos estudiosos situam” ou omita a data se ela não ajudar a história;
4. não transforme genealogias, símbolos ou cronologias teológicas em data absoluta sem explicar a escolha;
5. a revisão factual deve aprovar toda data mostrada em tela.
